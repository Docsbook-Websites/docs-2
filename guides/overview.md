# Guides

A guide is task-shaped: the title names a job, and the reader is done when the job is. Add one page per job, and list it here so people can find it.

Titles that start with a verb win, because readers scan for their own words rather than for feature names. When two guides keep explaining the same background, that background is a reference page — link both of them to it instead of repeating it twice.
