# Reference

Reference pages answer a narrow question fast. People arrive from a search box, read one row and go, so structure beats prose: one page per surface, one table per group of values, the same columns everywhere.

For each value, write what it does, what it defaults to, and what happens when it is wrong. That last part is what support answers by hand today.

Opinions and walkthroughs belong in the guides, which can link down here for the detail.
